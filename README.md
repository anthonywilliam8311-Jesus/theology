# Theology and Apologetics

## Post an article
Create a file in `articles/<topic>/your-title.md`:

```
---
title: My Title
date: 2026-10-05
excerpt: One sentence for the article card.
---
Your text...
```

Topic folders: theology, islamic-dilemma, apostolic-faith, atheism, hinduism, buddhism.
You can also set the topic inside the file with a `category:` line (it overrides the folder).
A new folder inside `articles/` becomes a new topic automatically.

Enable GitHub Pages: Settings > Pages > Deploy from branch `main` / root. Keep the repo public.

## Verse of the Day
Edit the `VERSES` list at the top of `js/app.js`. The verse changes automatically every day.
